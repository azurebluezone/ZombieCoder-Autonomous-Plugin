# Bootstrap Skill

## When to use
- Prototyping/admin panels
- Responsive layouts quickly
- Consistent components

## Key practices
- Use grid system correctly
- Customize via Sass variables or utilities
- Ensure accessibility where possible
- Avoid deep overrides unnecessarily

## Quick checklist
- [ ] Responsive at breakpoints
- [ ] Components accessible
- [ ] Consistent spacing/utilities
- [ ] No layout breakage
