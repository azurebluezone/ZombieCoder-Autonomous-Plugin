# Tailwind CSS Skill

## When to use
- Rapid UI development
- Design system with tokens
- Consistent spacing/typography

## Key practices
- Use design tokens/config
- Prefer utilities, extract components when repeated
- Responsive prefixes
- Accessibility considerations

## Quick checklist
- [ ] Config aligned to design tokens
- [ ] Responsive tested
- [ ] States covered (hover/focus/active)
- [ ] Purge/content configured
