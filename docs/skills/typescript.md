# TypeScript Skill

## When to use
- Type errors, strict mode, module resolution
- API contracts, DTOs, type guards
- Refactors with confidence

## Key practices
- `strict: true` where possible
- Prefer types/interfaces intentionally
- Narrow with type guards
- Avoid `any`; use `unknown` + guards
- Use utility types

## Quick checklist
- [ ] `tsconfig.json` appropriate
- [ ] No implicit any
- [ ] Types exported where needed
- [ ] Tests/typecheck pass
